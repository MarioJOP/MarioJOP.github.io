# Site pessoal — José Mário Oliveira Patrício

Site estático feito com HTML, CSS e JavaScript, pronto para o GitHub Pages.

## Publicar

1. Crie um repositório no GitHub (por exemplo, `MarioJOP.github.io`).
2. Envie estes arquivos para a branch `main`.
3. Em **Settings → Pages → Build and deployment**, escolha **GitHub Actions**.
4. Aguarde a action **Publicar no GitHub Pages** terminar.

Não é necessário instalar dependências nem executar uma etapa de build.

## Visualizar localmente

Abra o arquivo `index.html` no navegador. Para uma visualização mais fiel, use qualquer servidor HTTP local simples.
